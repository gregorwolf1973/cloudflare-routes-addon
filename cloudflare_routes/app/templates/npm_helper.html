NPM – Schnellübersicht
  1. NPM → Proxy Hosts → Add Proxy Host
  2. Domain Names: dein-hostname.de
  3. Scheme + Forward IP + Port eintragen
  4. WebSockets Support aktivieren (HA benötigt das)
  5. SSL → Request a new SSL Certificate oder Origin Cert hochladen
  6. „Force SSL" und „HTTP/2 Support" aktivieren
  7. Advanced → Nginx-Konfiguration einfügen
